## 7. 結論與總結

### 7.1 主要發現

1. **操作條件是最大干擾源**：FD004 的 6 種操作條件對所有感測器讀值造成顯著偏移，必須在分析前進行 OC 標準化。

2. **有效感測器**：21 個感測器中有 1 個為近常數（無資訊量），應予排除；其餘 20 個感測器在 OC 標準化後均展現退化趨勢。

3. **退化模式**：FD004 的 2 種故障模式（HPC + Fan Degradation）造成各引擎退化軌跡具有較大個體差異，比 FD001/FD003（單一故障模式）更難預測。

4. **PCA 健康指標**：第一主成分整合多感測器訊號，與 RUL 的 Spearman 相關 ρ = -0.6558，是一個有效的整合健康狀態指標。

5. **Random Forest 預測**：透過 OC 標準化 + 滑動視窗特徵，RF 達到 RMSE = 28.53 cycles，PHM'08 Score = 6273.9，展示了資料驅動方法在複雜多條件場景下的可行性。

### 7.2 後續改進方向

- 加入更長滑動視窗（如 50 cycles）或多尺度視窗特徵
- 嘗試 Gradient Boosting（XGBoost/LightGBM）提升預測精度
- 應用序列模型（LSTM、TCN）以完整捕捉時序依賴
- 對兩種故障模式分別建模，針對各自退化特性進行優化
